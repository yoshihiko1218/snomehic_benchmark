# snmCAT — File Inventory

**snmC2T-seq (snmCAT-seq, NOMe) pipeline** on human frontal cortex (donor **UMB5580**,
batch `190321_mCTseq_hs_29yr`, GSE140493), 100 single cells. Processed with **yap (v1.6.9)
`mct --nome`** (bismark methylome + STAR transcriptome + GpC accessibility), hg38.

Verified real NOMe accessibility: median **HCG 81.2%** (CpG meth) / **GCH 15.1%** (accessibility) /
HCH 4.6% (background) — GCH/HCH ≈ 3.3×, 92/100 cells GCH > 2× background.

## Top level
- `meta.tsv`, `meta_sorted.tsv` — ENA metadata for all GSE140493 SRRs (8494 rows).
- `RUNBOOK_nome.md` — the end-to-end pipeline recipe (start here to reproduce/extend).
- `fastq_brain/` — downloaded reads `SRR*_{1,2}.fastq.gz` + yap symlinks `SRR*-R{1,2}.fq.gz`.
- `mapping_brain/` — yap output tree (one `Group<k>/` per cell-group). Key outputs:
  - `Group*/allc/<cell>.allc.tsv.gz` — per-cytosine methylation, NOMe context (upstream+C+2down).
  - `Group*/rna_bam/*.feature_count.tsv` — RNA gene counts.
  - `stats/MappingSummary.csv.gz` — 92-col per-cell QC (the benchmark QC input).
  - `stats/hcg_gch_nome.tsv` — per-cell HCG/GCH/HCH site counts + mC rates (the accessibility table).
  - `stats/AllcPaths.tsv` — 100 ALLC paths.
- `JOBS.md` — job log + the full investigation history (which GSE140493 batches are NOMe vs not).
- `SESSION_NOTE_*.md` — per-session work log.

## codes/  (clean 00–05 pipeline)
- `00.build_star_index.sh` — SLURM job: build the STAR index with the env's STAR (2.7.3a) so it
  matches the aligner. One-time prereq; index lives in `/reference/hg38/star_2.7.10a_gencode.v36_sjdb100`.
- `mapping_config_nome.ini` — yap `--nome` config (num_upstr_bases=1 + NOMe mc_stat contexts).
  Generated by `yap default-mapping-config --mode mct --nome ...` (see RUNBOOK).
- `01.download.sh` — SLURM array: download cells from ENA into `fastq_brain/` (list `download_list_brain.txt`).
- `02.rename_symlink.sh` — yap-pattern symlinks `SRR*_1.fastq.gz -> SRR*-R1.fq.gz`.
- `03.patch_snakefiles.sh` — inject `bismark_reference`, `star_reference`, and `nome_flag_str='--nome'`
  into every `mapping_brain/Group*/Snakefile` (yap leaves these blank — required workaround).
- `04.run_mapping.sh` — SLURM array: run the per-Group snakemake (bismark + STAR + select-dna --nome + allc).
- `05.collect_hcg_gch.sh` — SLURM job: aggregate per-cell HCG/GCH/HCH counts + mC rates -> `stats/hcg_gch_nome.tsv`.
- `download_list_brain.txt`, `cells_brain.tsv` — the 100 cells (SRR/GSM) and their fastq URLs.
- `logs/{00.star_index,01.download,04.map,05.gch}/` — SLURM task logs.

## Pipeline order — see RUNBOOK_nome.md
download (01) -> rename (02) -> `yap start-from-cell-fastq` (--nome config) -> patch (03) ->
map (04) -> `yap summary -o mapping_brain` -> collect HCG/GCH (05).
